# OffSec Hub — Curated Offensive Security Resource Index

Original resource index built for the Hacker Playbook. Ethical use only.

## Mission
Centralize vetted tools, write-ups, and learning paths for authorized penetration testing, bug bounty, DFIR and security research. No copy-paste of existing collections — curated with context, risk ratings and use-cases.

## Structure
- `tools/` — categorized by phase with maturity rating
- `writeups/` — short, reproducible PoCs with scope notes
- `playbooks/` — per-environment checklists
- `resources.md` — living links to wikis, forums, databases

## Getting Started
1. Read `../HACKER_PLAYBOOK.md` for methodology
2. Use `resources.md` for tool discovery
3. Contribute via PR with evidence
