# Report Structure

## 1. Engagement Overview
- Client information
- Scope definition
- Engagement dates
- Team members

## 2. Reconnaissance Summary
- OSINT findings
- Technical recon results
- Asset inventory

## 3. Vulnerability Analysis
- discovered weaknesses
- Risk ratings
- Exploitability assessment

## 4. Exploitation Results
- Successful breaches
- Failed attempts
- Chain analysis

## 5. Post-Exploitation Findings
- Lateral movement
- Persistence mechanisms
- Data access

## 6. Recommendations
- Immediate fixes
- Long-term improvements
- Prioritization matrix

## 7. Appendices
- Full command output
- Tool versions
- IOC indicators
