# Hacker Playbook — Authorized Offensive Security

> **Ethical use only.** This playbook is for authorized penetration testing, bug bounty programs with explicit scope, and defensive security research. Unauthorized access is illegal and unethical. Always obtain written permission before testing.

## Overview
A structured framework for offensive security engagements — covering reconnaissance, exploitation, post-exploitation, red teaming, forensics, tools, labs and reporting.

## Quick Start
1. Review `00_Reconnaissance/notes.md` for engagement setup
2. Use the directory structure to organize findings, tools and reports
3. Contribute via PR with evidence and original writeups
